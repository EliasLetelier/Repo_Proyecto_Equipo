# Ficha Técnica

## Características de los datos

#### La base de datos se realizó mediante el Excel; cada columna representa una de las características generales de cada partido enfrentado entre Universidad de Chile y Colo-Colo, con el fin de conocer el ambiente y contexto de cada encuentro Estas columnas incluyen: 

#### Fecha en la cual se jugó.

#### Las veces que Colo-Colo y Universidad de Chile fueron locales.

#### ¿En cuál competición se enfrentaron (Torneo Nacional, Copa Chile y Supercopa)?

#### Árbitro encargado del encuentro.

#### Estadio en donde se realizó cada enfrentamiento.

#### Público

#### Goles por cada equipo

#### Resultado

## Variables incorporadas

#### Se ordenó de otra manera el apartado de resultados de la entrega anterior, por lo que se separó la cantidad de goles realizados por cada equipo, y el resultado final, con el fin de agilizar el proceso de creación de datos. El único dato sumado para este trabajo fue el del público presente en cada partido.

## Observaciones

#### Esta base de datos tiene como objetivo analizar los factores que pueden provocar faltas por parte de cada equipo, y el historial que hay entre estos dos equipos puede influir en la manera en que cada club pueda utilizar el contexto a favor o en contra. La base de datos combina variables cuantitativas y cualitativas.
